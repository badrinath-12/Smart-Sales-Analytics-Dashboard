# Smart Sales Analytics Dashboard

## Project Overview
Smart Sales Analytics Dashboard is a data analytics project developed to analyze sales data and generate meaningful business insights. It uses Python, SQL, and Streamlit to process, analyze, and present sales information through an interactive web-based dashboard.

## Technologies Used
- **Python:** Data processing and analysis.
- **SQL:** Data querying and retrieval.
- **Streamlit:** Interactive dashboard development.

## Key Features
- Sales data analysis using Python.
- Data querying and management using SQL.
- Interactive dashboard built with Streamlit.
- Visualization of sales performance and trends.
- User-friendly interface for exploring sales information.
- Data-driven insights to support business analysis.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/badrinath-12/Smart-Sales-Analytics-Dashboard.git
```

### 2. Navigate to the Project Folder

```bash
cd Smart-Sales-Analytics-Dashboard
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
streamlit run app.py
```

## Project Objective

To transform sales data into useful business insights through data analysis, SQL queries, and interactive visualizations.
